# 破站自救（v1）

状态：**已对齐** — Safari 向档位 B（系统级指引后置）。  
上级：[prd.md](prd.md) · Agent 规则：[`AGENTS.md`](../../AGENTS.md)。  
文档语言：中文 · 界面文案：**英文**。

## 目标

默认零配置，但 **Safari** 站点出问题时用户必须能**自救**——且不依赖自定义过滤规则。

## v1 内

| 能力 | 说明 |
|------|------|
| **全局暂停** | 临时关闭 **Safari** 拦截，状态清晰标「当前未受保护」 |
| **按站放行（Safari）** | 对破站站点临时和/或永久允许 |
| **可选报错** | 仅用户主动；字段最少；可匿名；若含 URL，仅用户确认的那一条 |

## 后置（随系统级能力）

| 能力 | 说明 |
|------|------|
| **系统级指引 / 按 App 处理** | 系统级 URL Filter 产品化后再补：如何关闭 Filter、能力边界说明 |

## 隐私

- 无静默上传浏览历史或「你访问过的站」。  
- 报错载荷最小化；不绑定后台遥测。  
- 对齐 `AGENTS.md` 规则 2 与 [prd.md](prd.md) §3。  

## v1 外（后续候选）

- Live Help / 远程「已知问题」CMS（档位 C）  
- 元素选择器、自定义规则  
- 若系统不干净支持，则不做复杂的按 App 白名单  

## UX 原则（界面英文）

- 主状态面 1–2 次点按即可到自救操作。  
- 平实用语，例如：`Pause protection`、`Allow this website`、`Report a problem`。  
- 报错**不要求**账号。
