## 一览

| 字段 | 值 |
|------|-----|
| **名称** | **Gleem** |
| **副标题** | **Block Ads & Trackers**（已锁定，英文） |
| **一句话** | 隐私优先的广告与追踪拦截：Safari + 系统级 App、策展规则包、一次解锁。浏览留在设备上。 |

| **主楔子** | 系统级 URL Filters，含在基础 IAP 内 |
| **商业** | 免费下载 + 一次非消耗型解锁 + Family Sharing |
