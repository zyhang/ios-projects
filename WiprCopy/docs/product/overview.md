## 一览

| 字段 | 值 |
|------|-----|
| **名称** | **Gleem** |
| **副标题** | **Block Ads & Trackers**（已锁定，英文） |
| **一句话** | 隐私优先的 **Safari** 广告与追踪拦截：安静可信、策展规则包、一次解锁。浏览留在设备上。 |
| **受众** | 海外重视隐私的 Apple 用户（美/欧等）— 界面英文 |
| **主叙事** | **C 为主**（可信安静工具）+ **B 为辅**（一次买断 / Family Sharing）；不以低价为主轴 |
| **产品路线** | Wipr 级基线 + **克制 plus**（可参考 AdGuard 高级能力，逐项过门槛） |
| **主楔子（v1）** | 出色的 **Safari** 拦截体验 |
| **后置** | 系统级全 App、Mac 客户端拦截 — 另论证 |
| **商业** | 免费下载 + 一次非消耗型解锁 + Family Sharing |
