## 约定

1. 新增/变更**产品决策**时更新 **prd.md**（及受影响专题）；不要把决策表写回 `AGENTS.md`。  
2. `AGENTS.md` 只保留必须遵守的 Agent 规则 + 指向 PRD 的引用。  
3. 专题文档展开细节，但不得与 PRD 已对齐决策冲突。  
4. **写文档用中文；写界面/商店用户文案用英文。**
