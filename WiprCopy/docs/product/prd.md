## 1. 一句话定义

**Gleem** — 面向海外用户的隐私优先 **Safari** 广告与追踪拦截：开箱即用、策展规则包、一次解锁；气质安静可信。浏览数据留在设备上。

| 字段 | 值 | 状态 |
|------|-----|------|
| **App 显示名** | Gleem | 已锁定 |
| **副标题** | Block Ads & Trackers | 已锁定 |
| 理想/立场文案 | 放商店描述、截图、应用内 About — **不**放副标题 | 见 [naming.md](naming.md) |

营销 one-liner（**英文**，面向用户；v1 不主推 system-wide）：

> Gleem — Block ads and trackers in Safari. One purchase. Privacy stays on your device.

（系统级 / 全 App / Mac 客户端拦截：后续论证通过后再改 one-liner 与商店宣称。）

---

## 2. 受众

- **主受众：** 使用 Apple 设备、重视隐私的用户（美国 / 欧盟 / 其他海外市场）
- 愿意为「开箱即用」的 Safari 拦截工具一次性付费
- 期望：无广告商交易、无可接受广告后门、名单持续维护；界面少折腾

**不为**中国市场支付习惯或国内浏览器生态做优化。Agent/协作者规则：[`AGENTS.md`](../../AGENTS.md) 规则 1。

---

## 3. 隐私原则（产品需求）

与 Wipr 级工具同等信任标准。完整 Agent 规则：[`AGENTS.md`](../../AGENTS.md) 规则 2。

| 要求 | 说明 |
|------|------|
| 浏览留本地 | 访问过的站点、被拦截请求等不用于分析、画像或遥测上传 |
| 不采集 | 不收集个人数据与浏览行为（无广告 SDK、无第三方分析、无静默追踪） |
| 优先系统过滤 | Content Blocker（及日后若有 URL Filters）— 由系统代为过滤；扩展不必读页面内容 |
| PIR / 基建 | 若未来上系统级：运营方**不得**得知用户查了什么；禁止可还原浏览历史的日志 |
| 可选报错 | 仅用户主动；字段最小化；不与浏览历史绑定 |
| 冲突处理 | **隐私 / 本地优先 > 功能炫技** |

## 4. 定位与已对齐决策

### 4.1 战略一句话

> **在复刻 Wipr 级冷静 Safari 体验的基础上做克制的 plus**（可从 AdGuard 等重型产品「偷学」少数高级能力，但每项过克制门槛）；**用能力与信任取胜，不以「比 Wipr 便宜」为主轴。**  
> **v1 先把 Safari 做深做稳**；系统级全 App、Mac 客户端拦截等 **后置论证**，避免战线过长。

### 4.2 主叙事（对用户说什么）

**B（省心买断）+ C（可信安静工具），偏重 C。**

| 层 | 含义 | 权重 |
|----|------|------|
| **C 主调** | 不看你、不烦你、拦住就走；Home 安静；信任与本地隐私 | **主** |
| **B 辅调** | 一次购买、无订阅压力、Family Sharing；完整性可感知 | **辅** |
| **不用作主轴** | 「比 Wipr 便宜」、促销感、堆功能仪表盘 | 禁止当第一印象 |

### 4.3 相对 Wipr / AdGuard

| 维度 | 决策 |
|------|------|
| 基线 | **Wipr 级**：极简壳、开箱、策展、少选项、冷静 |
| 路线 | **能力扩（plus）**，不是低价替代；也不是正面堆功能的「更重版」 |
| Plus 来源 | 可参考 AdGuard 等**高级能力清单**，逐项评估后「偷学」；默认拒绝整包复刻 |
| Plus 门槛（须同时满足） | ① 隐私/本地优先 ② 不破坏健康态 Home 的安静 ③ 不为高级用户打开「自写规则」大门 ④ 维护成本可承受 ⑤ 对 Safari 主场景有清晰收益 |
| 主楔子（v1） | **出色的 Safari 拦截体验**（Content Blocker + 策展包 + 自救 + 信任叙事） |
| 副楔子（v1） | **内置规则包**（结构 B）+ **克制 plus 能力**（清单见 §4.5；未论证前不进 MVP） |
| 后置楔子 | 系统级全 App（URL Filters）、Mac 客户端拦截等 — **论证通过后再写入 MVP / 商店宣称** |
| 定价叙事 | 信任、Safari 体验质量、维护与完整性；**不以低价 /「略便宜」作主卖点或锚定策略** |
| 商业 | **免费下载 + 一次非消耗型 IAP 全解锁** + **Family Sharing**；见 [commerce.md](commerce.md) |
| 名单 | 混合策展 **(C)**；见 [blocklists.md](blocklists.md) |
| 破站自救 | Safari 向档位 B（暂停 + 按站放行 + 可选报错）；系统级指引随系统级能力后置；见 [breakage-recovery.md](breakage-recovery.md) |
| 命名 | 短工具感；见 [naming.md](naming.md) |
| 隐私 | 本地优先；不采集浏览；无广告商；无可接受广告 |
| 明确不做（v1） | 以中文/区域深度当差异化；用户自写过滤规则；以低价当品牌主轴；后台浏览遥测；名单更新订阅制；**未论证的 system-wide 营销宣称** |

### 4.4 范围节奏（避免战线过长）

| 阶段 | 聚焦 | 状态 |
|------|------|------|
| **v1（当前）** | **Safari** 广告/追踪拦截产品化 | **锁定为上架主路径** |
| **后续论证** | 系统级全 App（URL Filters）、Mac 客户端/更深 Mac 拦截、与 Safari 的统一心智 | **未锁定**；不阻塞 v1 视觉与工程主线 |
| **禁止** | 在未论证前，把 UI/工程/商店文案默认写成「Safari + Apps system-wide」已交付 | |

### 4.5 Plus 能力原则（非完整清单）

- **默认姿态**：少即是多；Home 仍像安静工具，不像控制台。  
- **来源**：AdGuard 等重型产品的「高级」能力可作灵感池（例如更细的站点控制、更稳的破站自救、名单/包体验增强等）——**仅灵感，非承诺**。  
- **入库流程**：提案 → 过 §4.3 Plus 门槛 → 写入 PRD/专题 → 再进线框与实现。  
- **v1 已对齐的 plus 种子（仍克制）**：规则包分层（Core / Annoyances / Strict）、Safari 按站放行、可选最小化报错。  
- **未论证不进 v1**：元素选择器、完整统计仪表盘、用户导入名单、Web Extension 深度脚本等（部分可永后置）。

### 4.6 视觉气质（设计任务，非单选锁定）

重设计阶段产出 **至少两套方向** 再对比挑选（见 [`../design/`](../design/)）：

| 方向 | 气质 | 用途 |
|------|------|------|
| **冷静工具** | Wipr/系统设置感；短句、金属/中性、功能诚实 | 与 C 主叙事强对齐 |
| **干净生活** | 消噪、生活化、轻内容隐喻；仍须隐私可信、非儿童化/非杀毒腔 | 探索更宽情感面 |

两套都必须满足：海外英文、隐私可信、极简、非 VPN 霓虹/警报红。**先出可对比稿，再锁一版 tokens。**

## 5. MVP（v1 上架门槛）

**能力档：Safari 深做。** 上线首日兑现「安静、可信、Safari 好用」；**不**要求兑现系统级全 App。

### 5.1 范围内

| 领域 | 要求 |
|------|------|
| UI | **英文**界面 + 清晰隐私说明（不采集、本地优先） |
| **Safari** | **Content Blocker** 为主路径；支持名单 / 规则包开关 |
| 规则包 | 结构 **B** — 见 §5.3 与 [rule-packs.md](rule-packs.md) |
| 状态 | 是否启用、名单新鲜度（软诊断）、常见 Safari 错误配置 |
| 自救 | Safari：全局暂停 + 按站放行 + 可选最小化报错 — [breakage-recovery.md](breakage-recovery.md) |
| 名单 | 自动更新（技术需要时可有手动）— 只拉取规则；不上传浏览 |
| 平台 | **iPhone 优先**；iPad 与 Safari 路径一致时可纳入 v1；**Mac 客户端拦截后置论证**（不承诺 v1 完整 Mac 体验） |
| 系统级 | **不在 v1 必达**；见 §5.5 |

### 5.2 后置（非 v1 必达）

- **系统级全 App URL Filters**（含 PIR 管线）— 单独论证后再开  
- **Mac 客户端 / 系统级 Mac 拦截**产品化  
- Safari Web Extension（Extra 级）  
- 复杂远程报错后台、Live Help CMS  
- 拦截统计仪表盘、Vision Pro 打磨  
- 用户名单导入、正则编辑器、元素选择器  
- 深色模式打磨（高保真可先浅色）  
- 未过 Plus 门槛的 AdGuard 类高级功能  

### 5.3 规则包（v1）

| 包 | 作用 | 默认 | 用户可关？ |
|----|------|------|------------|
| **Core** | 基线广告、常见追踪、挖矿等 | **开** | 否（如有全局暂停则走暂停） |
| **Annoyances** | Cookie 墙、订阅弹窗、装 App 骚扰等（名单级） | **开** | 是 |
| **Strict** | 更激进；更容易破站 | **关** | 是 |

v1 以 **Safari** 输出为主。日后若上系统级，再尽量用同一套包开关驱动（一套心智模型）。v1 无自由自定义规则。详见 [rule-packs.md](rule-packs.md)。

### 5.4 名单

**混合策展 (C)：** 社区优质源 + 自选，经我们编译/QA。各包上游可不同；自有 exception 与热修。约每周 1–2 次刷新。许可证 + 英文 Acknowledgements。详见 [blocklists.md](blocklists.md)。

### 5.5 系统级后端（URL Filters）— 后置

| 项 | 决策 |
|----|------|
| v1 | **不作为上架门槛**；不阻塞 Safari 主路径的设计与工程 |
| 后续 | 另开论证与 spike（清单仍见 [url-filter-spike.md](url-filter-spike.md)） |
| 商店 / UI | **在论证通过前**，不默认宣称 *across apps* / *system-wide* 已交付 |
| 若未来做 | 倾向打进同一买断 IAP，**不为系统级另设核心第二 SKU**（可再确认） |

### 5.6 商业（v1）

| 项 | 决策 |
|----|------|
| 商店形态 | 免费下载 + **一个**非消耗型 IAP 解锁全部 **v1 能力** |
| 解锁包含（v1） | Safari 拦截 + 规则包 + 持续名单更新（+ 已纳入的克制 plus） |
| Family Sharing | 是（在解锁 IAP 上开启） |
| 定价 | **不以「略低于 Wipr」为政策**；按体验与市场对标定价；主叙事仍是信任与能力（见 [commerce.md](commerce.md)） |
| v1 不做 | 付费下载为主；名单更新订阅制；未交付的系统级另拆 SKU 营销 |

详见 [commerce.md](commerce.md)。

## 6. 技术约束

| 层 | 约束 |
|----|------|
| **Safari（v1）** | Content Blocker；更深层规则若需要再考虑 Web Extension（后置） |
| 系统级 | 后置；技术路径仍可能是 iOS/iPadOS/macOS 的 **URL Filters**（非 VPN）— 不锁 v1 排期 |
| 商业模式 | 独立开发者；持续名单；无广告商关系；无可接受广告后门 |
| 遥测 | 默认关 / 优先不做；名单更新只拉规则 — 永不上传浏览行为 |
| 架构偏好 | 系统负责过滤；App/扩展不为统计或调试去读页面内容 |

## 7. UX 产品约束（v1）

对线框与高保真具规范效力（不得漂移）：

| 约束 | 说明 |
|------|------|
| 导航 | **无 Tab**；Home 为根 + **More** push（Wipr 风格） |
| 健康态 Home | 一句状态文案（英文）；几乎无按钮 |
| 名单更新 | 自动；Home（及 v1 UI）**无**手动 Update 控件 |
| Welcome | 视觉优先；**内容以 Safari + 隐私/安静为主**（勿默认第三页或关键页卖 system-wide，除非已交付） |
| 自救 | 从 Home / More 1–2 次点按可达 |
| 文案密度 | 短英文、大留白、少控件 |
| 视觉 | 至少出 **冷静工具** 与 **干净生活** 两套方向对比后再锁 — §4.6 |

屏幕清单与流程：[`../wireframes/`](../wireframes/)（若仍写「Safari & Apps」系统级为主楔子，以实现时以 **本 PRD 为准** 改线框）。
