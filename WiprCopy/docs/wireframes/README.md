## 已定 UI 原则（产品层，非视觉皮肤）

| 原则 | 做法 |
|------|------|
| 极简 | 健康状态几乎无按钮；一屏一事 |
| 导航 | **无底部 Tab**；Home 为根，**More** 进入次级（参考 Wipr） |
| 名单 | **仅自动更新**；Home **无**「Update」按钮 |
| Welcome | **视觉优先**；叙事以 **Safari + 安静/隐私** 为主（不默认卖 system-wide） |
| 调性 | 大留白、短**英文**文案、少控件；C 主 B 辅 |

视觉语言以 `docs/design/` 新稿为准，**不以** v1 归档 tokens 为准。
