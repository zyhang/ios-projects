## 已定 UI 原则（产品层，非视觉皮肤）

| 原则 | 做法 |
|------|------|
| 极简 | 健康状态几乎无按钮；一屏一事 |
| 导航 | **无底部 Tab**；Home 为根，**More** 进入次级（参考 Wipr） |
| 名单 | **仅自动更新**；Home **无**「Update」按钮 |
| Welcome | **3 页视觉优先**（噪音 / Safari+Apps / 本地隐私）；设置细节留给 Enable 页 |
| 调性 | 大留白、短**英文**文案、少控件 |

视觉语言（色板、字体、组件样式）以 `docs/design/` 新稿为准，**不以** v1 归档 tokens 为准。
