Support

Stillwall is being built to block ads, trackers, and annoyances in Safari on iPhone and iPad. It is not yet available on the App Store.

Planned requirements

  • iPhone or iPad on iOS / iPadOS 26 or later
  • Safari — Stillwall works through Safari extensions; other browsers are not supported
  • Stillwall Pro is planned to work across your iPhone and iPad under the same Apple ID

Enable protection

  1. Open Stillwall.
  2. Follow Set Up Safari Protection.
  3. Enable both Stillwall extensions using the exact Settings path shown in the app, then allow website access as instructed.
  4. Return to Stillwall — Home should show protection On.

The final iOS 26 Settings path is being verified before release.
If Home does not show On, protection is not active yet. Complete the system steps above— we never show “protected” when Safari access is missing.

A site looks broken

  • Turn off the global switch in Stillwall, or
  • Open the Stillwall Safari extension on that site and choose Pause on this site, then Resume when finished.

Strict Mode (Pro) is more aggressive and can break some sites—try turning it off first.

Report an issue

The planned reporting flow opens from the Stillwall Safari extension on the affected page. The report is designed to be prefilled with the current site’s domain, and you can review everything before sending. Reports are used only to fix blocking—never to build a profile of your browsing.

YouTube & X ads

Enhanced blocking for YouTube and X is planned for Safari websites only, not the native apps. Final behavior is still being validated.

Tap to Block

Tap to Block is planned for Stillwall Pro. The intended flow lets you select page elements from the Safari extension. Final interaction details are still being validated; rules are designed to stay on your device.
