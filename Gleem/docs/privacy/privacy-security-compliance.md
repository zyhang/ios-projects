# 隐私、安全与合规

## 1. 核心承诺

Gleem 的零数据承诺：

- 不创建用户账号。
- 不接入第三方分析、广告归因或 session replay。
- 不上传浏览历史、访问域名、拦截命中或 App 使用情况。
- 不使用 IDFA 或自建设备标识。
- 不出售、共享或用于广告的数据。
- 支持信息只有在用户主动发送时离开设备。

## 2. 数据分类

### 2.1 仅保存在设备

- allowlist。
- 暂停状态。
- 功能开关。
- 规则版本与完整性状态。
- 最近规则更新错误。
- StoreKit entitlement 的本地表示。

### 2.2 基础设施可能处理

- 规则/CDN 请求的 IP、时间、User-Agent 等必要网络元数据。
- 未来 OHTTP/PIR 运行所需的隐私保护请求。
- Apple 处理的 TestFlight、App Store、StoreKit 和系统诊断数据。

要求：

- Gleem 不把基础设施元数据用于用户画像。
- 日志关闭或最短保留。
- 隐私政策披露供应商类别和用途。

### 2.3 用户主动提供

- 支持邮件地址。
- 用户主动填写的说明。
- 用户选择附加的截图。
- 当前域名及本地诊断字段。

发送前必须展示，用户可编辑或取消。

## 3. 权限说明

### 3.1 Content Blocker

- 用途：向 Safari 提供声明式拦截规则。
- 能力：Safari 执行规则。
- 不读取：网页内容和浏览历史。

### 3.2 Gleem Extra

- 用途：处理 YouTube/X 动态广告元素。
- Host 权限：仅 `youtube.com`、`x.com` 及必要子域。
- 不申请：所有网站权限。
- 不处理：私信、输入内容、账号凭据。
- 不上传：页面内容或命中信息。

### 3.3 URL Filter

- 用途：对更多 App 的 URL 请求做允许/阻断判断。
- 用户必须明确授权。
- 必须解释其不等于 VPN 或 DNS 服务。
- 必须披露 PIR/OHTTP 架构和基础设施角色。

## 4. 数据流

### 4.1 Safari 基础保护

```text
规则包 → 主 App 验签 → App Group → Content Blocker → Safari 本地执行
```

没有浏览数据返回主 App 或服务器。

### 4.2 YouTube/X Extra

```text
Safari 页面 → 本地内容脚本判断 → 本地隐藏元素
```

页面数据不离开设备。

### 4.3 规则更新

```text
客户端 → CDN/对象存储 → manifest/package
```

请求中不包含账号、设备 ID、浏览域名或命中数据。

### 4.4 用户反馈

```text
用户选择发送 → 预览字段 → 系统邮件 → 支持邮箱
```

没有后台静默上传。

## 5. 安全要求

- manifest 和规则包签名验证。
- package 哈希与大小限制。
- 公钥固定，私钥隔离。
- 禁止远程下发可执行 JavaScript。
- 依赖和规则源固定版本。
- App Group 文件原子写入。
- 错误规则 fail open 或回滚。
- 所有端点支持 TLS。
- CI 日志不输出密钥和签名私钥路径。

## 6. 供应链

每个第三方依赖与规则源记录：

- 名称与版本。
- 官方来源。
- 校验值。
- 许可证。
- 商业使用/再分发条件。
- 隐私影响。
- 更新责任人。

首版尽量使用 Apple 原生框架，避免引入第三方 SDK。

## 7. App Store 审核

提交材料需要：

- 清楚说明每个扩展的用途。
- 展示 Gleem Extra 只访问 YouTube/X。
- 说明 TestFlight/正式版的实际功能，不使用占位或伪造状态。
- 提供可用的规则服务和支持 URL。
- IAP 完整可审核，正式版说明年订阅、试用和恢复购买。
- App Privacy 与实际网络行为一致。
- 如果 Apple 要求 URL Filter 额外授权或配置，先获得批准再提交相关能力。

## 8. 法律与产品边界

- 不绕过付费墙。
- 不提供内容盗版、视频下载或地域解锁。
- 不把广告拦截包装成恶意软件防护，除非另有证据和范围。
- 不使用竞品商标造成来源混淆。
- 最终品牌需做目标市场商标核查。
- 上游规则许可未确认前不得进入生产包。

## 9. 隐私政策必须说明

- 收集什么：默认不收集个人或浏览数据。
- 不收集什么：历史、域名、拦截命中、标识符。
- 规则更新如何工作。
- Gleem Extra 权限为何需要。
- 未来 URL Filter/PIR 如何保护查询。
- 支持邮件如何处理和保留。
- 用户如何撤销权限、删除本地数据和取消订阅。
- 基础设施供应商类别。
- 政策变更方式。

## 10. 隐私验收

- 抓取 App 与扩展所有网络请求。
- 验证没有未知第三方端点。
- 验证请求不包含设备标识、浏览域名和命中数据。
- 验证关闭反馈流程时没有上传。
- 验证卸载 App 后本地配置删除。
- 验证 privacy manifest 和 App Store 声明一致。
