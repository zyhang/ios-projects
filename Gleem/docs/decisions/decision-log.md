# 决策记录

## 1. 使用说明

本文件记录已经由产品负责人确认的关键决策。修改已确认决策时，需要补充新的记录并注明替代关系，不直接删除历史。

状态定义：

- **已确认**：当前实施必须遵守。
- **待验证**：事实或外部依赖尚未确认，不能写成既定能力。
- **暂缓**：当前版本不做，后续是否进入范围需重新决策。

## 4. 暂缓事项

- 自定义规则和 Tap to Block。
- 拦截数量、节省流量、能耗或碳排估算。
- iCloud 设置同步。
- Mac、Apple TV、Vision Pro。
- 恶意网站、成人内容和家长控制。
- 账号系统。
- 规则编译器、客户端或后端开源。
- 月订阅和终身买断。

## 5. 禁止偷换的概念

- “跨 App URL 过滤”不等于“识别并删除所有 App 原生广告”。
- “零数据收集”不等于“完全没有任何网络请求”；规则更新与 PIR 基础设施仍需透明披露。
- “私有 TestFlight 发布”不等于“公开 App Store 正式发布”。
- “Pro 页面预览”不等于“Pro 功能已经可用”。
- “候选品牌”不等于“已完成商标清查”。
