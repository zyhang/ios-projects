Stillwall — App Review Notes

NO ACCOUNT
Stillwall does not use accounts or sign-in. Leave demo account fields as N/A.

WHAT THE APP IS
Stillwall is a Safari content blocker + Safari web extension for ads, trackers, and annoyances. It is NOT a VPN and does NOT block ads system-wide or inside third-party apps (including the native YouTube / X apps).

HOW TO ENABLE (required to see protection)
1. Install and open Stillwall.
2. Complete onboarding: Welcome → Set Up in Safari.
3. When prompted, open iOS Settings → Apps → Safari → Extensions (path may vary slightly by iOS version).
4. Enable all Stillwall Content Blockers and the Stillwall Web Extension, then allow website access (Allow All Websites) as directed in-app.
5. Return to Stillwall. When setup is complete, Home shows category controls with default free categories enabled. Home does not show a global On/Off protection badge.

FREE PATH FOR REVIEW
All free features work without purchase: independent Ads, Privacy, Annoyances, and Regional blocking controls, plus site pause in the Safari extension popup. Home has no global protection switch.

PRO (OPTIONAL)
Pro (YouTube & X in Safari, Battery Boost, Strict Mode, Tap to Block) is an auto-renewable yearly subscription with a 1-month free trial, then $14.99/year, Family Sharing supported. You may skip Pro to review free Safari blocking.

SAFARI EXTENSION POPUP (3 items)
1) Pause / Resume on this site
2) Tap to Block
3) Report issue

FILTER LISTS
Third-party filter lists are used under their licenses. Attributions are listed in-app (About / Acknowledgements) once finalized (see product V-004).
