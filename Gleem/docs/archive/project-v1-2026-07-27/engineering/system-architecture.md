# 系统架构

> **已归档（2026-07-27，project-v1）**：本文属于全量文档快照的一部分，不再作为现行权威。见 [归档说明](../README.md)。重构请写到 `docs/`。

## 1. 架构目标

- 基础 Safari 保护不需要读取浏览历史。
- YouTube/X 页面级增强仅获得最小域名权限。
- 规则更新可以验证来源、完整性和版本，并能回滚。
- App、扩展和后台任务共享一致状态。
- 失败时优先保留网络可用性。
- 两周版本与未来 Pro 架构解耦。

## 2. 阶段 A 架构：Safari TestFlight

```text
┌──────────────────────────────┐
│ SwiftUI 主 App               │
│ 引导 / 状态 / 放行 / 暂停    │
│ 规则更新 / 反馈 / Pro Preview│
└──────────────┬───────────────┘
               │ App Group
      ┌────────┴────────┐
      │ Shared State     │
      │ Settings/Rules   │
      └──────┬─────┬────┘
             │     │
┌────────────▼─┐ ┌─▼────────────────┐
│ Content       │ │ Gleem Extra      │
│ Blocker       │ │ Safari Web Ext.  │
│ 声明式规则     │ │ YouTube / X      │
└───────────────┘ └──────────────────┘
             ▲
             │ HTTPS + 签名清单
┌────────────┴───────────────────────┐
│ 静态规则交付                       │
│ manifest / rule packages / flags   │
└────────────────────────────────────┘
```

### 2.1 主 App

职责：

- 首次引导。
- 读取系统和本地保护状态。
- 触发规则更新与 Content Blocker reload。
- 管理 allowlist、暂停和专项模块开关。
- 展示 Pro 预览。
- 生成用户主动反馈和诊断。

主 App 不负责：

- 观察用户访问的网站。
- 记录拦截事件。
- 在后台持续运行。

### 2.2 Content Blocker Extension

职责：

- 向 Safari 提供预编译声明式规则。
- 屏蔽请求、隐藏元素和处理常见干扰项。

约束：

- 不读取页面内容。
- 不执行网络请求。
- 不记录命中。
- 规则必须在交付前通过格式和数量校验。

### 2.3 Gleem Extra

职责：

- 处理仅靠 Content Blocker 难以稳定完成的动态页面。
- YouTube 视频/页面广告专项逻辑。
- X Promoted Posts DOM 级隐藏。

权限：

- `youtube.com` 及必要子域。
- `x.com` 及必要子域。
- 不申请 `<all_urls>`。

防护：

- 每个站点模块独立开关。
- 脚本异常时 fail open，不阻塞主内容。
- 远程配置只允许关闭或选择已内置模块，不下载执行任意代码。

## 3. 阶段 B 架构：Pro URL Filter

```text
┌────────────────┐
│ SwiftUI 主 App │
│ StoreKit/状态   │
└───────┬────────┘
        │ 配置
┌───────▼─────────────────┐
│ NEURLFilterManager      │
│ 系统执行 URL 判定        │
└───────┬─────────────────┘
        │ Bloom filter + PIR
┌───────▼───────────────────────────┐
│ URL Filter Control Provider      │
│ 获取预过滤数据与参数              │
└───────┬───────────────────────────┘
        │ Apple OHTTP relay
┌───────▼───────────────────────────┐
│ Gleem PIR 服务                    │
│ 隐私查询数据库 / 版本化数据集      │
└───────────────────────────────────┘
```

### 3.1 能力边界

- 过滤 WebKit 与 `URLSession` 发出的 URL 请求。
- 对其他网络栈只有在目标 App 主动参与时才能获得相同能力。
- 不能检查并删除原生 App UI 中的单条内容。
- 不能承诺原生 YouTube/X 广告完全消失。

### 3.2 上线前置条件

- Apple 相关 entitlement/配置可用于目标分发构建。
- OHTTP relay 和 CloudKit/Identity & Trust 配置完成。
- PIR 服务器通过隐私和容量测试。
- 断网、超时、错误判定和服务不可用策略明确。
- 默认采用 fail open，除非产品另行审慎决策。

## 4. 共享数据

建议通过 App Group 保存：

- 当前有效规则版本。
- 规则包路径与哈希。
- allowlist。
- 暂停状态与到期时间。
- Gleem Extra 模块开关。
- 最近一次成功更新时间。
- 内置回退规则版本。

不得保存：

- 浏览历史。
- 命中过的域名列表。
- 请求 URL 日志。
- 用户设备标识或广告标识符。

## 5. 状态来源

保护状态必须由以下来源组合计算：

- Safari Content Blocker 系统状态。
- Gleem Extra 授权状态。
- 本地规则包完整性。
- 规则新鲜度。
- 暂停与 allowlist 状态。
- 未来 Pro 的 `NEURLFilterManager.status`。
- StoreKit entitlement 状态。

UI 不直接缓存最终文案状态，而是从可验证事实生成。

## 6. 失败与降级

| 故障 | 降级策略 |
| --- | --- |
| 无网络 | 继续使用最近有效规则 |
| manifest 下载失败 | 保留当前版本，指数退避 |
| 签名/哈希失败 | 拒绝新包，记录本地诊断 |
| 新规则编译失败 | 保留旧包，不 reload |
| Gleem Extra 模块异常 | 关闭对应站点模块，保留基础规则 |
| 规则误杀严重 | 远程下发禁用/回滚清单 |
| PIR 服务不可用 | fail open，避免系统级断网 |
| 订阅有效但过滤器未启用 | `One Quick Step`，引导授权 |

## 7. 安全边界

- 规则 manifest 使用固定公钥验证。
- 私钥不进入客户端、仓库或 CI 日志。
- 规则包只允许声明式数据，不远程下发可执行 JavaScript。
- YouTube/X 可执行脚本随 App 版本发布；远程配置只能控制启停和静态参数。
- 所有网络端点使用 HTTPS。
- 依赖与规则源固定版本并保留来源证据。

## 8. 不在首版引入

- 用户账号与身份服务。
- 通用事件分析。
- 远程日志。
- 自定义脚本下载。
- 多区域动态实验平台。
- 复杂微服务。
